# Agence Landing Page

A digital agency landing page demonstrating a complete business website layout.

[Live demo](https://shanajtech.github.io/AgenceLandingPage/) · [Source code](https://github.com/shanajtech/AgenceLandingPage)

## Page highlights

Hero call to action, service cards, work gallery, agency introduction, client reviews, quote form interface, and footer.

## Built with

HTML5, CSS3, Bootstrap, jQuery, and Font Awesome.

## Run locally

```bash
git clone https://github.com/shanajtech/AgenceLandingPage.git
cd AgenceLandingPage
```

Open `index.html` in a browser, or serve the folder with your editor's local preview server. No package installation or build step is required.

## Project structure

| Path | Contents |
| --- | --- |
| `index.html` | Page markup |
| `css/style.css` | Main styles |
| `css/media.css` | Media-query styles |
| `js/script.js` | Page interactions |
| `images/` | Image assets |

## Portfolio focus and scope

This is a static frontend practice project, showcasing section composition, typography, spacing, image placement, and Bootstrap layouts. It does not include a backend, quote submission service, or customer management. Some links are layout placeholders. Review the live page at your target screen size when evaluating the design.
